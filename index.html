Countdown

Home-screen widget & daily reminder

Widget (Scriptable, free)

  1. Install Scriptable from the App Store.
  2. Tap the button below to copy the widget script.
  3. Open Scriptable, tap +, paste, and name it Countdown.
  4. Long-press your home screen, tap +, add a Scriptable widget (small or medium).
  5. Long-press that widget, tap Edit Widget, set Script to Countdown and When Interacting to Run Script.

If you add or change a countdown, or switch tone, copy and paste the script again.

Daily reminder (Shortcuts, free)

  1. Shortcuts → Automation → + → Time of Day (e.g. 7:00), Daily, Run Immediately.
  2. Add action Run Script (Scriptable), pick Countdown, and set its input to the text notify.
  3. Add action Get Dictionary from Input, then Show Notification: Title = dictionary value title, Body = value body.
